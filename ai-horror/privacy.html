AI怪談朗読 制作ツール

プライバシーポリシー

制定日: 2026年9月18日

「AI怪談朗読 制作ツール」（以下「本ツール」）は、esaka（個人開発者、以下「開発者」）が、開発者自身が運営する YouTube チャンネルの動画投稿と分析を自動化するために利用する、非公開の個人用ツールです。一般に配布・提供しておらず、利用者は開発者本人に限られます。本ポリシーは、本ツールにおける情報の取り扱いについて説明するものです。

1. 利用者は開発者本人のみです

本ツールは開発者のローカル環境（開発者の PC）でのみ動作します。第三者に配布しておらず、第三者がサインインして利用することはありません。したがって、第三者の個人情報を収集することはありません。

2. Google アカウントに対して求める権限

本ツールは、開発者自身の Google アカウントに対して、次の 2 つの権限（スコープ）を求めます。

  • https://www.googleapis.com/auth/youtube.force-ssl
    開発者自身のチャンネルへ動画をアップロードし、タイトル・説明欄・サムネイル・公開予約などのメタデータを更新するために使用します。
  • https://www.googleapis.com/auth/yt-analytics.readonly
    開発者自身のチャンネルの再生数・視聴維持率・流入経路などの分析データを読み取るために使用します。読み取り専用です。

これらの権限は、開発者自身が所有するチャンネルに対してのみ行使されます。他者のチャンネルやアカウントへアクセスすることはありません。

3. 保存する情報と、その保存場所

  • OAuth アクセストークン／リフレッシュトークン — 開発者の PC のローカルファイルにのみ保存されます。外部のサーバーへ送信・保管することはありません。
  • 動画のメタデータと分析値 — 動画 ID・タイトル・公開日時・再生数などを、制作管理のためにローカルのファイルへ記録します。これらはすべて開発者自身のチャンネルに関する情報です。

4. 第三者への提供

本ツールが取得した情報を、第三者へ提供・販売・共有することはありません。広告配信・解析サービス等の外部サービスへ送信することもありません。

5. Google ユーザーデータの利用範囲

本ツールによる Google API から取得した情報の利用・転送は、Google API Services User Data Policy（Limited Use requirements を含む）に準拠します。取得した情報は、本ポリシー第 2 項に記載した目的（開発者自身のチャンネルの投稿と分析）にのみ使用します。

6. アクセス権の取り消しと、データの削除

  • Google アカウントの「サードパーティ アプリとサービス」から、本ツールのアクセス権をいつでも取り消せます。
  • ローカルに保存されたトークンファイルを削除すれば、本ツールは以後 API へアクセスできなくなります。

7. 子どもの情報

本ツールは開発者本人のみが利用するものであり、13 歳未満の子どもを含む第三者から情報を収集することはありません。

8. 本ポリシーの変更

本ポリシーを変更する場合は、本ページに変更後の内容と制定日を掲載します。
